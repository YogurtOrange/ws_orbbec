# 04 启动与验证

## 1. 加载环境

```bash
source /opt/ros/humble/setup.bash
source ~/ws_orbbec/install/setup.bash
```

安装脚本结束时会把上面两行询问是否写入 `~/.bashrc`（默认写入；带 `# >>> orbbec_camera` 标记，重复运行只更新不重复追加），写入后新开终端自动生效，不必每次手动 source。

手动写入（可选）：

```bash
source /opt/ros/humble/setup.bash
source ~/ws_orbbec/install/setup.bash
```

## 2. 枚举设备

```bash
ros2 run orbbec_camera list_devices_node
```

期望输出包含设备名、序列号、VID/PID、固件版本，例如：

```
name: Gemini 2, serial: CL8xxxxxxxxx, pid: 0x0670, vid: 0x2bc5, ...
```

无输出或提示无设备时，见 [05-常见问题](05-常见问题.md)。

## 3. 机型与 launch 文件

| `--camera` 关键词 | launch 文件 | 适用设备 |
|---|---|---|
| `gemini2` | `gemini2.launch.py` | Gemini 2 |
| `gemini2l` | `gemini2L.launch.py` | Gemini 2 L |
| `gemini210` | `gemini210.launch.py` | Gemini 210 |
| `gemini305` | `gemini305.launch.py` | Gemini 305 |
| `gemini330` | `gemini_330_series.launch.py` | Gemini 330/335/336 系列 |
| `gemini435le` | `gemini435_le.launch.py` | Gemini 435Le |
| `gemini345` | `gemini345.launch.py` | Gemini 345 |
| `femto_bolt` | `femto_bolt.launch.py` | Femto Bolt |
| `femto_mega` | `femto_mega.launch.py` | Femto Mega |
| `astra2` | `astra2.launch.py` | Astra 2 |
| `dabai_dcw2` | `dabai_dcw2.launch.py` | Dabai DCW2 |
| `lidar` | `lidar.launch.py` | Pulsar 雷达 |

不确定机型时直接看 `install/orbbec_camera/share/orbbec_camera/launch/` 目录。

## 4. 启动

```bash
ros2 launch orbbec_camera gemini2.launch.py
```

常用覆盖参数（以 Gemini 2 为例）：

```bash
ros2 launch orbbec_camera gemini2.launch.py \
  color_width:=1280 color_height:=720 color_fps:=30 \
  enable_depth:=true enable_color:=true
```

## 5. 验证图像与控制

新终端：

```bash
source ~/ws_orbbec/install/setup.bash

ros2 topic list | grep camera          # 话题
ros2 topic hz /camera/color/image_raw  # 彩色帧率（应约等于 fps）
ros2 topic hz /camera/depth/image_raw  # 深度帧率
ros2 topic echo /camera/depth/camera_info --once
```

图像可视化：

```bash
rqt_image_view        # 选择 /camera/color/image_raw
# 或
rviz2                 # 添加 Image 显示，选择话题
```

调用服务：

```bash
ros2 service call /camera/get_sdk_version orbbec_camera_msgs/srv/GetString '{}'
```

## 6. 脚本化验证

```bash
./scripts/verify.sh    # 交互选择验证对象；可选择是否做启动冒烟测试
```

冒烟测试会在 30 秒内启动一次 launch 并检查话题，失败时打印节点日志尾部，便于直接定位。

## 7. 停止与清理

- `Ctrl+C` 结束 launch
- 清理构建产物：`./scripts/uninstall.sh`
- 连 udev/源码一起清理：`./scripts/uninstall.sh`，菜单选 `3`

## 8. 二进制安装（apt）的差异

二进制版不经过 `colcon build`，环境与验证命令略有不同：

```bash
source /opt/ros/humble/setup.bash
ros2 launch orbbec_camera gemini2.launch.py

./scripts/verify.sh    # 交互选择“2) apt 二进制安装”
```

apt 二进制只通过“未克隆本仓库”的单文件脚本获得（仓库入口已移除 apt，避免仓库源码闲置）：

- `bash install_official.sh` 选 `2`

卸载：`sudo apt remove ros-humble-orbbec-camera ros-humble-orbbec-description`。

注意：

- 写入 `~/.bashrc` 时，apt 方式只写 `source /opt/ros/humble/setup.bash`（包在系统目录，没有工作空间 setup 需要加载）。
- 二进制包为官方源版本（2.9.3），与源码编译（v2.10.7）不要同时启用，`ros2 pkg prefix orbbec_camera` 指向哪个取决于最后 source 的环境。
- 二进制版不能修改 launch/源码；需要改参数请改用源码编译（已克隆仓库用 `./scripts/install.sh`，未克隆用 `install_official.sh` 选 1）。
