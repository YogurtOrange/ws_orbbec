# 03 单文件脚本：官方方式（源码构建 / apt 二进制）

适合：**没有克隆本仓库**的用户，只想用官方源码或官方 apt 包，或想对照官方文档手动操作。

> 严格区分：已经克隆本仓库的用户不要用本方式，请直接用仓库内 `./scripts/install.sh` 编译仓库源码。若把 `install_official.sh` 放进本仓库目录运行，脚本会检测到并直接退出，提示改用仓库入口。

官方文档：<https://github.com/orbbec/OrbbecSDK_ROS2/blob/v2-main/README_CN.MD>

## 1. 推荐：只下载一个脚本

适合没有本仓库的用户。**只需要 [install_official.sh](file:///home/yjc/ws_orbbec/install_official.sh) 一个文件**，后续的目录创建、依赖安装、源码克隆（或 apt 安装）全部由脚本完成，不依赖本仓库其他文件。

下载（任选其一）：

```bash
# 从 Release 下载（推荐，版本固定，与 tag 对应）
curl -fsSLO https://github.com/YogurtOrange/ws_orbbec/releases/latest/download/install_official.sh

# 从 Release 指定版本下载
curl -fsSLO https://github.com/YogurtOrange/ws_orbbec/releases/download/sdk-v2.10.7/install_official.sh

# 从仓库 main 分支直连下载（始终最新）
curl -fsSLO https://raw.githubusercontent.com/YogurtOrange/ws_orbbec/main/install_official.sh
```

运行：

```bash
bash install_official.sh
```

### 1.1 运行后先选一种方式

脚本会先说明两种方式的区别，再让你选：

| | 1) 源码编译（推荐） | 2) apt 二进制 |
|---|---|---|
| 版本 | 官方 **v2.10.7**（默认固定版本，也可选最新 tag） | 官方 apt 源 **2.9.3**，比源码版旧 |
| 耗时 | 约 2–3 分钟（克隆 + 编译） | 约 30 秒（直接安装） |
| 安装位置 | `~/ws_orbbec/install`（工作空间） | `/opt/ros/humble`（系统目录） |
| 能否改代码/launch | 能，改 `src` 后重编译或用 `--symlink-install` 改 launch 即时生效 | 不能，deb 包内文件只读 |
| 需要编译器 | 需要（cmake/gcc） | 不需要 |
| 卸载 | 删 `~/ws_orbbec` | `sudo apt remove ros-humble-orbbec-camera ros-humble-orbbec-description` |

选择建议：

- 需要调参、改 launch、跟官方最新功能 → 选 **1**
- 只想最快跑起来、不打算动代码 → 选 **2**

### 1.2 选 1：源码编译（6 步）

```text
1) 环境自检       Ubuntu 22.04、ROS 2 Humble、架构、工具链、USB 设备
2) 安装依赖       33 个 apt 包（含 v2.10.x 新增的 Eigen/OpenCV/yaml-cpp 等）
3) 克隆官方源码   创建 ~/ws_orbbec/src，clone 官方 tag（GitHub 失败自动回退 Gitee）
4) 编译           colcon build --symlink-install（并行任务数菜单选择）
5) 安装 udev 规则 /etc/udev/rules.d/99-obsensor-libusb.rules
6) 验证           ros2 run orbbec_camera list_devices_node 枚举设备
```

安装完成后：

```bash
source ~/ws_orbbec/install/setup.bash
ros2 launch orbbec_camera gemini2.launch.py
```

### 1.3 选 2：apt 二进制（4 步）

```text
1) 环境自检       Ubuntu 22.04、ROS 2 Humble、架构、sudo
2) apt 安装       sudo apt-get install ros-humble-orbbec-camera ros-humble-orbbec-description
3) 安装 udev 规则 取 /opt/ros/humble/share/orbbec_camera/udev/ 下的规则
4) 验证           ros2 run orbbec_camera list_devices_node 枚举设备
```

这条路径**不克隆源码、不编译、不创建 `~/ws_orbbec`**。安装完成后：

```bash
source /opt/ros/humble/setup.bash
ros2 launch orbbec_camera gemini2.launch.py
```

> 二进制版是官方 apt 源里的 2.9.3，功能与 2.10.7 有差异；需要改 launch/参数时请改用方式 1（源码编译）。

行为约定（两种方式通用）：

- 运行后可选“先预览安装步骤”，只打印命令、不执行
- 结束时询问是否写入 `~/.bashrc`：源码方式写 `ROS + 工作空间` 两行，apt 方式只写 ROS 一行；带标记块，重复运行只更新不重复追加
- 源码方式安装根目录固定 `~/ws_orbbec`，不存在自动创建
- 源码方式下 `src/OrbbecSDK_ROS2` 已存在时，先备份为 `OrbbecSDK_ROS2.bak.<时间戳>` 再克隆，避免新旧配置混用
- 国内网络（源码方式）：源码来源处选 `2`（Gitee 镜像）

### 已克隆本仓库时（不要用本脚本）

已克隆本仓库请改走仓库入口，只做仓库源码编译，源码一律用仓库内的 `src/OrbbecSDK_ROS2`，不会克隆官方仓库，也没有 apt 选项：

```bash
cd ~/ws_orbbec
./scripts/install.sh    # 选 1：用仓库源码编译；选 2：预览
```

> 本节的单文件脚本仅用于“没有本仓库”的机器，两者不要交叉使用。

## 2. 纯手动步骤（完全按官方文档）

### 2.1 加载 ROS 环境

```bash
source /opt/ros/humble/setup.bash
```

### 2.2 安装依赖

```bash
sudo apt install libgflags-dev nlohmann-json3-dev \
  libeigen3-dev libopencv-dev libyaml-cpp-dev pkg-config \
  ros-$ROS_DISTRO-image-transport ros-${ROS_DISTRO}-image-transport-plugins ros-${ROS_DISTRO}-compressed-image-transport \
  ros-$ROS_DISTRO-image-publisher ros-$ROS_DISTRO-camera-info-manager \
  ros-$ROS_DISTRO-diagnostic-updater ros-$ROS_DISTRO-diagnostic-msgs ros-$ROS_DISTRO-statistics-msgs ros-$ROS_DISTRO-xacro \
  ros-$ROS_DISTRO-backward-ros ros-$ROS_DISTRO-pluginlib ros-$ROS_DISTRO-message-filters ros-$ROS_DISTRO-rclcpp-action \
  ros-$ROS_DISTRO-geometry-msgs ros-$ROS_DISTRO-rcl-interfaces ros-$ROS_DISTRO-rmw \
  ros-$ROS_DISTRO-ament-index-python ros-$ROS_DISTRO-launch ros-$ROS_DISTRO-launch-ros \
  libdw-dev libssl-dev mesa-utils libgl1 libgoogle-glog-dev \
  python3-psutil python3-tabulate python3-yaml
```

> v2.10.x 比旧版本新增了 Eigen / OpenCV / yaml-cpp / pluginlib / message_filters / rclcpp_action 等依赖，缺一个都会在 `colcon build` 阶段报 `Could not find ...`。

### 2.3 克隆并编译

```bash
mkdir -p ~/ws_orbbec/src
cd ~/ws_orbbec/src
git clone https://github.com/orbbec/OrbbecSDK_ROS2.git
cd OrbbecSDK_ROS2
git checkout v2.10.7

cd ~/ws_orbbec
colcon build --event-handlers console_direct+ --cmake-args -DCMAKE_BUILD_TYPE=Release
```

> 内存较小的 ARM 板（尤其是 2GB / 4GB）请限制并发，否则容易卡顿甚至被系统 OOM 终止。单文件脚本会用菜单让你选择并行数（默认推荐值由内存与核数计算）；手动编译时：
>
> ```bash
> MAKEFLAGS=-j2 CMAKE_BUILD_PARALLEL_LEVEL=2 \
>   colcon build --symlink-install --parallel-workers 2 --cmake-args -DCMAKE_BUILD_TYPE=Release
> ```
>
> 取值与原理见 [05 常见问题](05-常见问题.md) 的“内存不足”。

> 根目录固定为 `~/ws_orbbec`。若该目录下已有 `src/OrbbecSDK_ROS2`，不要再克隆一份，二选一：
> - 删除/改名备份后重新克隆；
> - 在现有仓库里切换分支：`git -C ~/ws_orbbec/src/OrbbecSDK_ROS2 fetch origin v2-main && git -C ~/ws_orbbec/src/OrbbecSDK_ROS2 checkout v2-main`

### 2.4 安装 udev 规则（必需）

```bash
cd ~/ws_orbbec/src/OrbbecSDK_ROS2/orbbec_camera/scripts
sudo bash install_udev_rules.sh
```

脚本等价于：

```bash
sudo cp 99-obsensor-libusb.rules /etc/udev/rules.d/99-obsensor-libusb.rules
sudo udevadm control --reload-rules && sudo udevadm trigger
```

然后**重新插拔相机**。不要用 `sudo` 运行 ROS 节点。

### 2.5 启动

```bash
source ~/ws_orbbec/install/setup.bash
ros2 run orbbec_camera list_devices_node
ros2 launch orbbec_camera gemini2.launch.py
```

## 3. 版本策略：固定版本 vs 自动最新

| 策略 | 如何选择 | 特点 |
|---|---|---|
| 固定版本（默认） | 版本问题处回车或输入 `1` | 可复现、教程与排障基线稳定；官方发新版不会自动升级 |
| 自动最新 tag | 输入 `2` | 运行时用 `git ls-remote` 解析官方最新 tag；需要网络，可能因官方改动而不兼容 |

推荐**对外发布教程时用固定版本**（别人装出来和你一致）；需要“跟进最新”时选最新版本，验证通过后再更新脚本里的默认版本号。

```text
请选择要安装的版本：
  1) 固定版本 v2.10.7（已验证可用，推荐）
  2) 最新版本（自动获取官方最新 tag，可能不兼容）
```

无 TTY 环境（CI/脚本调用）自动选择固定版本，不会卡住。

## 4. 与仓库源码方式的区别

| | 仓库源码（02） | 单文件脚本（本文） |
|---|---|---|
| 前提 | 已克隆本仓库 | 只需一个脚本文件 |
| 源码来源 | 本仓库 v2.10.7，已内置 SDK 库（与官方一致） | 脚本从 GitHub tag 重新克隆（绝不复用仓库内源码）；也可选 apt 二进制，不下载源码 |
| 是否联网 | 编译不需要 | 必须 |
| 版本稳定性 | 固定，教程可复现 | 固定 tag 时可复现；选最新版本则随官方更新；apt 固定为源里的 2.9.3 |
| 彩色流默认 | 跟随设备默认 | 跟随设备默认 |
| 能否改代码 | 能 | 源码方式能；apt 方式不能 |

## 5. 注意

- 官方 `v2-main` 不支持 `gemini2 XL` 等老机型（见官方分支支持表），老设备请用 `main` 分支
- 固定安装根目录为 `~/ws_orbbec`，不存在时脚本自动创建
- 若 `colcon build` 报找不到 `backward_ros`，说明依赖没装全，回到 2.2
