# 02 仓库源码：开箱即用（使用本仓库已配置好的源码）

适合：**已经克隆本仓库**的用户。本入口只编译仓库内的 `src/OrbbecSDK_ROS2`，不会去官方仓库克隆，不提供“官方克隆”作为保底做法，也不提供 apt（避免仓库源码闲置）；仓库源码缺失时脚本直接报错，请重新克隆本仓库。

> 没有克隆本仓库的用户不要走这里，请用 [03 单文件脚本](03-方式B-官方方式.md)（源码克隆或 apt 二进制）。

## 1. 一键安装

```bash
cd ~/ws_orbbec
./scripts/install.sh
```

不带参数运行后，在“请选择安装方式”处直接回车（默认 1）即为本方式。

结束时脚本会询问是否把 `source` 行写入 `~/.bashrc`（默认写入，带标记块、可重复运行不会重复追加），此后新开终端自动生效。

验证阶段默认用 gemini2 的 launch 文件；其他机型见 [04-启动与验证](04-启动与验证.md)。

想先确认脚本动作：运行时在菜单中选择 `4`（预览），再选择要预览的安装方式。

## 2. 本仓库源码相对官方的差异

`src/OrbbecSDK_ROS2` 已预先配置：

| 项 | 说明 |
|---|---|
| 版本 | v2.10.7（官方最新），SDK 库随源码提供（`orbbec_camera/SDK/{x64,arm64}/lib/libOrbbecSDK.so.2.10.6`） |
| 本地修改 | 无（源码与官方 v2.10.7 一致） |
| 网络 | 编译不需要联网（依赖已装好的前提下） |

不需要联网克隆，也不依赖 GitHub 可达性。

## 3. 分步执行（等价于一键脚本）

```bash
cd ~/ws_orbbec

# 1) 自检
./scripts/check_env.sh

# 2) 依赖
./scripts/install_deps.sh

# 3) 编译（内部会 source /opt/ros/humble/setup.bash）
./scripts/build_ws.sh

# 4) udev（必须）
./scripts/install_udev.sh

# 5) 验证
./scripts/verify.sh --camera gemini2
```

## 4. 编译做了什么

```bash
source /opt/ros/humble/setup.bash
cd ~/ws_orbbec
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
```

产物在 `install/`，其中：

- `install/orbbec_camera/lib/orbbec_camera/`：节点可执行文件（含 `list_devices_node`）
- `install/orbbec_camera/share/orbbec_camera/launch/`：各机型 launch 文件
- `install/orbbec_camera/share/orbbec_camera/udev/99-obsensor-libusb.rules`：udev 规则来源

## 5. 启动

```bash
source ~/ws_orbbec/install/setup.bash
ros2 run orbbec_camera list_devices_node
ros2 launch orbbec_camera gemini2.launch.py
```

新开终端看图像：

```bash
source ~/ws_orbbec/install/setup.bash
rqt_image_view          # 选 /camera/color/image_raw
# 或
rviz2
```

## 6. 换机型

```bash
./scripts/install.sh --camera gemini330
ros2 launch orbbec_camera gemini_330_series.launch.py
```

机型关键词与 launch 的映射见 [04-启动与验证](04-启动与验证.md)。
