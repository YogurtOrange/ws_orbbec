# 05 常见问题

## 1. 权限与 udev

### `Permission denied` / `No device found` / 打开设备失败

原因：未安装 udev 规则，普通用户无权访问 USB 设备。

```bash
cd ~/ws_orbbec
./scripts/install_udev.sh
```

然后**拔插相机**。不要用 `sudo ros2 launch ...` 绕过，会导致环境与文件权限混乱。

确认规则生效：

```bash
ls -l /etc/udev/rules.d/99-obsensor-libusb.rules
lsusb | grep -i 2bc5
```

### 改了规则仍无效

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
# 重新插拔，或重置 USB 控制器
```

## 2. 检测不到相机

| 检查项 | 命令 / 处理 |
|---|---|
| USB 口是否 3.0 | `lsusb -t`，应显示 `5000M`，而不是 `480M` |
| 是否经过 Hub | 直连主板/笔记本 USB 口 |
| 线缆 | 使用相机原装或认证 USB3 线，劣质线会掉速/掉线 |
| 供电 | 部分机型需外部供电 |
| 设备号 | `lsusb` 中是否有 `2bc5:xxxx` |

USB 2.1 下可能出现能枚举但无图像、帧率极低，日志会提示降分辨率，请换 USB3 口/线。

## 3. 编译失败

### `Could not find a package configuration file provided by "backward_ros"` 等

依赖缺失：

```bash
./scripts/install_deps.sh
```

### `colcon: command not found`

```bash
sudo apt install python3-colcon-common-extensions
```

### 内存不足（ARM 板常见）

直接运行 `./scripts/build_ws.sh`，在提示处输入并行数（例如 `2`）。

或加 swap 后重试。

### 报错后想重来

```bash
rm -rf build install log
./scripts/build_ws.sh
```

`log/latest_build/` 下有完整编译日志。

## 4. 启动失败

### 提示找不到 launch 文件

机型与 launch 不匹配，查 [04-启动与验证](04-启动与验证.md) 的映射表，或直接：

```bash
ls ~/ws_orbbec/install/orbbec_camera/share/orbbec_camera/launch/
```

### 提示 `Library not loaded: libOrbbecSDK.so.2`

SDK 库未随包安装，确认源码完整：

```bash
ls ~/ws_orbbec/src/OrbbecSDK_ROS2/orbbec_camera/SDK/x64/lib/
```

缺失时还原仓库内源码：重新克隆本仓库，或 `git -C ~/ws_orbbec/src/OrbbecSDK_ROS2 checkout -- .`。

### 彩色与深度不同步、帧率异常

先用默认参数启动，确认稳定后再调 `color_width/height/fps`；带宽不足时降低分辨率或关闭不需要的流。

## 5. 其他

### 多台设备

```bash
ros2 run orbbec_camera list_devices_node
ros2 launch orbbec_camera multi_camera.launch.py
```

### 远程/SSH 无显示

`rviz2`、`rqt_image_view` 需要 X11；SSH 下用 `ssh -X`，或用 `ros2 topic echo`/录包分析。

### 固件版本过旧

按官方 README 的固件版本表升级；升级工具与包在官网产品页下载。

### 完全重置

```bash
./scripts/uninstall.sh    # 菜单选 3：构建产物 + 源码 + udev 规则
git clone https://github.com/orbbec/OrbbecSDK_ROS2.git src/OrbbecSDK_ROS2  # 重新拉取源码
```

## 6. 收集日志

```bash
ros2 run orbbec_camera ob_benchmark_node      # 带宽/帧率统计（按需）
dmesg | tail -50                              # USB 掉线
~/ws_orbbec/log/latest_build/                 # 编译日志
```

提 issue 时附上：`uname -a`、`lsusb -t`、`list_devices_node` 输出、launch 完整日志。
