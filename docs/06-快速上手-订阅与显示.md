# 06 快速上手：话题订阅与显示

目标：订阅相机发布的图像话题，显示 RGB 与深度两个窗口。示例代码在
[examples/quickstart](../examples/quickstart)。

---

## 1. 启动相机

```bash
source /opt/ros/humble/setup.bash
source ~/ws_orbbec/install/setup.bash
ros2 launch orbbec_camera gemini2.launch.py      # 按机型替换 launch 文件
```

涉及的话题：

| 话题 | 编码 | 说明 |
|---|---|---|
| `/camera/color/image_raw` | `rgb8` / `bgr8` | 彩色图 |
| `/camera/depth/image_raw` | `16UC1` | 深度图，单位毫米 |

---

## 2. 运行示例

**Python 版**：

```bash
~/ws_orbbec/examples/quickstart/python/run.sh
~/ws_orbbec/examples/quickstart/python/run.sh --no-depth
```

**C++ 版**（先编译一次）：

```bash
~/ws_orbbec/examples/quickstart/cpp/build.sh
~/ws_orbbec/examples/quickstart/cpp/run.sh
```

窗口中按 `q` 退出。

### 参数

Python：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--color-topic` | `/camera/color/image_raw` | 彩色话题 |
| `--depth-topic` | `/camera/depth/image_raw` | 深度话题 |
| `--alpha` | `0.05` | 深度伪彩对比度 |
| `--no-depth` | 关闭 | 只显示彩色 |

C++ 用 ROS 参数：

```bash
./cpp/run.sh --ros-args -p alpha:=0.08
./cpp/run.sh --ros-args -p enable_depth:=false
```

---

## 3. 数据流

```text
orbbec_camera 节点
  ├─ color/image_raw ─┐
  └─ depth/image_raw ─┤
                      ▼
              转 BGR / 深度伪彩
                      ▼
                  cv2.imshow()
```

彩色图转为 BGR 后显示；深度图按毫米值压缩到 0~255，再套伪彩映射。
