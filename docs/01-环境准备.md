# 01 环境准备

## 1. 最低要求

| 项 | 要求 |
|---|---|
| 操作系统 | Ubuntu 22.04 LTS（amd64 / arm64） |
| ROS | ROS 2 Humble（`/opt/ros/humble/setup.bash`） |
| 磁盘 | 源码 + 编译产物约 1.5 GB |
| 接口 | USB 3.0 Type-C / Type-A 直连（不要经 USB Hub） |
| 权限 | 可用 `sudo`；相机的 udev 规则必须安装 |

> 脚本以 Ubuntu 22.04 为基准；其他版本运行时会被询问是否继续，但不保证依赖包名一致。

## 2. 先跑一遍自检

```bash
cd ~/ws_orbbec
./scripts/check_env.sh
```

检查内容：Ubuntu 版本、ROS 2 发行版、CPU 架构、`colcon/cmake/gcc/git`、USB 设备（VID `2bc5`）、udev 规则、源码是否就绪。

期望输出（示例）：

```
[完成] 操作系统：Ubuntu 22.04
[完成] ROS 2 发行版：humble（/opt/ros/humble/setup.bash）
[完成] 目标架构：amd64
[完成] 工具链：colcon 已安装
[警告] USB：未检测到 Orbbec 设备（VID 2bc5），请确认已插好相机与 USB3 线缆
[完成] 环境自检通过
```

未插相机只是警告，不影响安装；udev 未装也只是提示，安装脚本会自动补上。

## 3. ROS 2 Humble 安装（未安装时）

按官方文档安装：

- 官方地址：<https://docs.ros.org/en/humble/Installation/Ubuntu-Install-Debs.html>
- 装完确认：

```bash
source /opt/ros/humble/setup.bash
ros2 --help
```

本教程不重复安装 ROS 2 本体，请先按官方文档装好 Humble。

## 4. 依赖清单及其作用

脚本安装的依赖（官方 README + `orbbec_camera/package.xml` v2.10.x 新增项）：

| 依赖 | 作用 |
|---|---|
| `libgflags-dev`、`nlohmann-json3-dev`、`libgoogle-glog-dev` | 参数解析 / JSON / 日志 |
| `libeigen3-dev`、`libopencv-dev`、`libyaml-cpp-dev`、`pkg-config` | 数学库 / 图像处理 / 配置解析（v2.10 新增） |
| `ros-humble-image-transport`、`image-transport-plugins`、`compressed-image-transport` | 图像话题传输与压缩 |
| `ros-humble-image-publisher`、`camera-info-manager` | 测试发布 / 相机内参管理 |
| `ros-humble-diagnostic-updater`、`diagnostic-msgs`、`statistics-msgs` | 诊断与统计 |
| `ros-humble-pluginlib`、`message-filters`、`rclcpp-action` | 插件机制 / 消息同步 / Action |
| `ros-humble-geometry-msgs`、`rcl-interfaces`、`rmw` | 消息与中间件接口 |
| `ros-humble-xacro`、`backward-ros`、`launch`、`launch-ros`、`ament-index-python` | URDF / 崩溃回溯 / 启动 |
| `libdw-dev`、`libssl-dev`、`mesa-utils`、`libgl1` | backward-ros、OpenSSL、OpenGL 运行时 |
| `python3-psutil`、`python3-tabulate`、`python3-yaml` | 诊断脚本依赖 |

一键安装：

```bash
./scripts/install_deps.sh   # 交互确认后安装
```

## 5. 目录与命名约定

统一使用 `ws_<用途>` 形式的工作空间命名，本教程固定使用：

- `~/ws_orbbec`：相机 SDK 与教程（所有安装模式统一安装到这里）
- `~/ws_robot`：机器人上层应用（示例）

源码放在 `src/`，构建产物 `build/`、`install/`、`log/` 均由 `colcon` 生成，不要入库。

## 6. 版本说明

- 本仓库锁定 `OrbbecSDK_ROS2` **v2.10.7**（官方最新 tag），SDK 动态库随源码提供（`SDK/{x64,arm64}/lib/libOrbbecSDK.so.2.10.6`）
- 单文件脚本有两项：源码编译（v2.10.7 的 tag，可选固定版本或最新版本）或 apt 二进制（官方源 2.9.3，装完即用但不可改代码）
- 若教程中的命令与官方不一致，以官方文档为准，并在本仓库提 issue
